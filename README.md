# CC GitHub workshop resources

Hands-on GitHub learning materials for the University of Montana Cybersecurity Collective.

## Start here
- [Copyable README and profile templates](workshop-starters.md)
- [Student handout](student-handout.md)
- [Publishing safety challenge](safety-challenge.md)
- [Completed practice example](https://github.com/GavinGME/cc-github-example)

## Bring
A laptop, charger, email access, and your GitHub authentication device if you use one. No Git installation is required for the main workshop. Experienced participants can use a repository they own and are allowed to edit. Beginners can start a harmless practice repository.

## What you will do
Create or choose a repository, make useful commits, improve documentation, review publishing safety, improve your profile, and exchange feedback.

## Privacy and attribution
Private practice and local drafts are welcome. Review contents and sharing permission before publishing. The linked log-analysis code is a supplied teaching example. Describe your own contribution when adapting it.

## Next step
Choose one small improvement, decide when to finish it, and keep your project link.
